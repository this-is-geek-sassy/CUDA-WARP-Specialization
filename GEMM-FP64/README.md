# Matrix Multiplication Test Case Generator

This Python utility generates datasets for validating matrix multiplication algorithms. It creates pairs of input matrices ($A$ and $B$), computes their dot product ($C$), and saves all three to CSV files.

This is designed to help verify the correctness of custom Linear Algebra implementations (e.g., in C++, CUDA, or Assembly) by comparing your output against the ground truth generated by NumPy.

## Requirements

* Python 3.x
* NumPy

To install the required dependency:

```bash
pip install numpy
````

## How to Use

1.  **Configure Test Cases:**
    Open the Python script and locate the `test_definitions` list at the bottom of the file. Add or modify tuples to define your desired matrix dimensions.

    **Format:** `(rows_A, cols_A, cols_B, type)`

      * `rows_A`: Number of rows in Matrix A ($M$)
      * `cols_A`: Number of columns in A / Number of rows in B ($K$)
      * `cols_B`: Number of columns in Matrix B ($N$)
      * `type`: Generation method (`'random'` or `'identity'`)

    **Example:**

    ```python
    test_definitions = [
        (512, 512, 512, "random"),  # Standard square multiplication
        (128, 256, 64, "random"),   # Rectangular multiplication
        (100, 100, 100, "identity") # Identity matrix check
    ]
    ```

2.  **Run the Script:**

    ```bash
    python generate_matrices.py
    ```

3.  **Access Data:**
    The script creates a directory named `test_cases/` containing the generated CSV files.

## Output Format

For every test case index `n` (starting at 1), three files are generated:

  * **`A_n.csv`**: Input Matrix A
  * **`B_n.csv`**: Input Matrix B
  * **`AB_n.csv`**: The Expected Result (A × B)

The files are standard CSVs with integer values and no headers.

## Notes

  * **Value Range:** The script generates integers between **-10 and 10**.
  * **Large Matrices:** The script is configured to handle large dimensions (e.g., 8192x8192). Be aware that generating CSVs for matrices of this size will produce multi-gigabyte files.

## ⚠️ GPU Architecture Configuration

Before building the project, you **must** update the `Makefile` to match your specific NVIDIA GPU's Compute Capability.

The default configuration is set for **Ada Lovelace** (e.g., RTX 4090, L4). If you are running on different hardware, you will get an error or suboptimal performance.

1. Open the `Makefile`.
2. Locate the `NVCCFLAGS` variable.
3. Update the `-arch=sm_XX` flag.

```makefile
# Default is sm_89 (Ada Lovelace)
NVCCFLAGS := -I. -O3 --ptxas-options=-v -arch=sm_89
````

# DGEMM Benchmark Automation Script

This Bash script automates the performance testing of the `dgemm` matrix multiplication binary. It iterates through specified kernels and test cases, performs warmup runs, averages execution times across multiple iterations, and presents the results in a formatted table.

## Features

* **Automated Iteration:** Loops through user-defined lists of Kernels and Test Cases.
* **Warmup Routine:** Performs a "silent" run before measurement to ensure caches are warm.
* **Averaging:** Runs each configuration 3 times and calculates the average execution time to reduce noise.
* **Output Parsing:** Automatically extracts the execution time from the binary's standard output.
* **Formatted Output:** distinct columns for Test Case, Kernel ID, and Average Time.

## Prerequisites

* Bash shell (Linux/macOS/WSL)
* `awk` (standard on most Unix systems, used for floating-point calculations)
* The compiled `dgemm` binary located at `./bin/dgemm` (or updated path).

## Configuration

Open `benchmark.sh` in a text editor to modify the parameters at the top of the file:

```bash
# Path to your executable
BINARY_PATH="./bin/dgemm"

# List of Kernel IDs to test
KERNELS=(2 3 4 5 7 8 9 10 11 12)

# List of Test Case IDs to run
TEST_CASES=(3 4)
````

## Usage

1.  **Make the script executable:**

    ```bash
    chmod +x benchmark.sh
    ```

2.  **Run the benchmark:**

    ```bash
    ./benchmark.sh
    ```

## Output Format

The script outputs a clean table to the console:

```text
Test Case    Kernel     Avg Time       
----------------------------------------
3            2          0.0452
3            3          0.0410
...
```

## How It Works

1.  **Arguments:** The script calls the binary using the format:
    `$BINARY_PATH [test_case] [kernel]`
2.  **Time Extraction:** The script assumes the binary prints the execution time to `stdout`. It specifically looks for the **very last number** (integer or float) printed in the output string.
      * *Note:* Ensure your binary prints the time in seconds (or your desired unit) as the final numerical value.
